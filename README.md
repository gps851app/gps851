# 851 GPS Faker - GitHub Pages

這個頁面作為 851 GPS Faker APP 的 Deep Link 中繼頁，
讓 LINE 等通訊軟體可以正確顯示可點擊連結。

## 使用方式

分享連結格式：
```
https://你的帳號.github.io/gps851/open.html?type=point&lat=25.0330&lng=121.5654&name=位置名稱
```

點擊連結後會自動跳轉到 851 GPS Faker APP。

## 路線分享格式
```
https://你的帳號.github.io/gps851/open.html?type=route&name=路線名稱&data=BASE64資料
```
